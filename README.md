# 🚀 Galaxy Strike

Galaxy Strike is a fast-paced 3D space shooter game built with Unity 6. Take control of a powerful spacecraft, navigate through deep space, and engage in intense battles against hostile enemy ships.

## 🎮 Gameplay

* Pilot a futuristic spaceship through space.
* Destroy incoming enemy spacecraft.
* Dodge enemy attacks and survive as long as possible.
* Earn points by eliminating enemy ships.
* Challenge yourself to achieve the highest score.

## ✨ Features

* 3D Space Combat
* Responsive Spaceship Controls
* Enemy AI Spaceships
* Projectile Shooting System
* Score Tracking
* Visual Effects and Explosions
* Unity 6 Powered Gameplay

## 🛠️ Built With

* Unity 6
* C#
* Universal Render Pipeline (URP)

## 📂 Project Structure

Assets/ - Game Assets, Models, Materials, Scripts, Prefabs

Packages/ - Unity Package Dependencies

ProjectSettings/ - Unity Project Configuration

## 🚀 Getting Started

### Prerequisites

* Unity 6 or later
* Git

### Installation

1. Clone the repository:

```bash
git clone https://github.com/RibhuMitra/Galaxy-Strike.git
```

2. Open Unity Hub.
3. Click **Add Project**.
4. Select the cloned project folder.
5. Open the project in Unity.
6. Press **Play** to start the game.
